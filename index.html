FLAGSHIP PROJECT

PostPro

AI-Simulated Caption, Hashtag & Song Generator

PHP • MySQL • HTML • CSS • JavaScript

Your All-in-One Social Media Content Companion

PostPro is a PHP-based web application designed to simplify social media content creation. Users can upload a photo, select a mood, and receive relevant caption suggestions, hashtags, and song recommendations in one convenient platform. The project focuses on making content discovery easier through a structured database, mood-based suggestions, and a user-friendly interface.

Technical Transparency: PostPro utilizes an AI-simulated suggestion system powered by structured mood taxonomy and relational database queries, rather than an external live third-party AI API.

PostPro — Architectural Overview

Core Objective: Simplify social media content creation by generating mood-based captions, hashtag recommendations, and soundtrack pairings in one unified PHP application.

Architecture: Relational MySQL database schema structuring moods, categorized tags, and media tracks. Secure PHP sessions with authentication and password recovery.

Transparency: Powered by structured mood taxonomy and relational database queries rather than an external live AI API.

Key Learning Outcomes:
  • Designed and normalized relational MySQL database schema
  • Implemented server-side authentication & session handling in PHP
  • Built responsive user dashboard and copy interactions in JavaScript
